## How to read dependencies

This register separates prerequisites from corequisites for the fictional B.Tech CSE curriculum. A prerequisite is an earlier course that supplies declared preparation. A corequisite is a course taken in the same semester, such as the theory subject paired with a laboratory. Similarity between subjects does not create an extra prerequisite. The lists below contain only the relationships recorded in the canonical contract.

The phrase none specified means that the contract declares no earlier-course requirement for that subject. It does not prove that the topic is easy or that outside knowledge is irrelevant. Likewise, an empty corequisite entry means no same-semester requirement is declared. The register does not specify registration waivers, equivalence rules or alternate entry routes.

## Machine Learning preparation

Machine Learning (HCE-CSE502), Semester 5, requires Probability and Statistics (HCE-CSE303), Design and Analysis of Algorithms (HCE-CSE304), and Linear Algebra for Computing (HCE-CSE404). These relationships connect numerical observations, computational reasoning and vector-based representation. Artificial Intelligence is studied in the same semester but is not listed as a prerequisite for Machine Learning.

Machine Learning Laboratory (HCE-CSE505) has Probability and Statistics and Linear Algebra for Computing as earlier prerequisites. Machine Learning itself is its same-semester corequisite. The laboratory's prerequisite list is not assumed to be identical to the theory course's list.

## Natural Language Processing preparation

Natural Language Processing (HCE-CSE603), Semester 6, requires Artificial Intelligence (HCE-CSE501) and Machine Learning (HCE-CSE502). The language course builds on those earlier subjects but does not require completion of Semester 7 Deep Learning. A conceptual connection to neural models should not be converted into an unlisted registration dependency.

Natural Language Processing Laboratory (HCE-CSE605) requires the same two earlier courses and pairs with Natural Language Processing as a corequisite. Information Retrieval is another Semester 6 subject; its relevance to language search does not make it an earlier prerequisite for NLP.

## Deep Learning preparation

Deep Learning (HCE-CSE701), Semester 7, requires Machine Learning (HCE-CSE502) and Linear Algebra for Computing (HCE-CSE404). Both must be retained when answering what to study beforehand. The linear algebra requirement remains explicit even though it is also part of Machine Learning's earlier preparation.

Deep Learning Laboratory (HCE-CSE705) lists Machine Learning and Linear Algebra for Computing as earlier prerequisites and Deep Learning as the same-semester corequisite. NLP is a useful conceptual connection but is not a declared prerequisite for Deep Learning. The complete table remains authoritative when a short description mentions only the most prominent dependency.

## Projects and interpreting missing relationships

Capstone Project I follows Software Engineering Project and Research Methods Seminar. Capstone Project II follows Capstone Project I. These links preserve the project's staged preparation without supplying unlisted submission dates or project topics. For timing, consult the calendar's course-specific milestones.

A response should distinguish what the contract requires from what might be helpful background. State every listed prerequisite for the requested course and identify same-semester partners separately. Do not add requirements because two courses share vocabulary or because a later application combines their methods.
