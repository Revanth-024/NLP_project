## Course description

Multilayer neural methods for learning hierarchical representations from data, building on Machine Learning.

## Prerequisites

Earlier-course prerequisites: Machine Learning (HCE-CSE502); Linear Algebra for Computing (HCE-CSE404).

The related course is Deep Learning Laboratory (HCE-CSE705), a 2-credit laboratory in Semester 7. The theory course is its same-semester corequisite, not an earlier prerequisite. The laboratory's own earlier prerequisites are Machine Learning (HCE-CSE502); Linear Algebra for Computing (HCE-CSE404).

### Networks and parameter learning

Multilayer perceptrons compose successive transformations into representations used for prediction. Forward propagation describes the flow from inputs to outputs, while backpropagation relates an objective to changes in parameters. The discussion distinguishes model structure from the procedure used to fit it. Machine Learning supplies the earlier concepts of examples, generalization and evaluation; Linear Algebra for Computing supplies the vector and matrix language used to describe transformations.

### Optimization and regularization

Optimization concerns how parameters are adjusted during learning. Regularization addresses excessive adaptation to the available observations. A small training error can coexist with poor behaviour on new data, so the course examines model evaluation alongside the training process. Students explain learning choices and their consequences rather than interpreting every change in a loss curve as evidence of a better deployed model. The emphasis remains on the approved major topics, without adding a separate institutional benchmark requirement.

### Convolutional representations

Convolutional neural networks organize computations around local patterns and shared transformations. This offers a useful connection to Computer Vision, another Semester 7 course, while the two subjects retain different focuses. Deep Learning examines the neural architecture and representation-learning perspective; Computer Vision concerns visual interpretation tasks. Comparisons should account for the kind of input and evaluation problem rather than assuming that every neural network architecture suits every observation.

### Sequences and attention-based architectures

Recurrent networks provide a way to carry information along a sequence. Attention-based architectures offer another view of relationships between positions. These themes connect with the contextual language representations encountered in NLP during Semester 6. NLP is not declared as a prerequisite for this course; its appearance earlier in the curriculum is a conceptual connection, not an extra registration rule. The comparison helps students explain why the same family of methods can appear in different application-oriented subjects.

### Evaluation and explanation

Model evaluation examines the evidence supporting a neural system's predictions. Students distinguish successful learning on a particular collection from a claim of universal understanding. Representations are interpreted through the task and data used to construct them. The associated laboratory provides a setting for observing trained behaviour and explaining an artifact during practical assessment. No named model, computing platform or commercial service is mandated by this synthetic syllabus.

## Expected learning outcomes

Students should be able to explain forward and backward propagation, connect optimization with model fitting, discuss regularization and generalization, and compare convolutional, recurrent and attention-based architectures. The topic headings above organize the approved major topics for reading; they are not a newly defined five-unit contract. Deep Learning shares predictive evaluation with Machine Learning and contextual representation ideas with NLP, while concentrating on multilayer neural methods.
